# SUBNET KING 1.0

## Google Play release notes

- Calculate Variable Length Subnet Masks for IPv4 and IPv6 networks.
- Add departments and required host counts for practical subnet planning.
- View network addresses, subnet masks, CIDR prefixes, usable ranges, and broadcast addresses.
- Save and review calculation history locally on your device.
- Updated SUBNET KING branding and app logo.

## Release details

- Version name: 1.0
- Version code: 1
- Minimum Android version: Android 9 (API 28)
- Target Android version: Android 14 (API 34)
